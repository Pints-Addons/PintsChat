Pint's Chatbox v1.0 - a clean, dark chat box
(WoW Classic Era / Hardcore / Forever)

REQUIRES
  Nothing.

INSTALL
  Unzip so the folder sits at:  World of Warcraft\_classic_era_\Interface\AddOns\PintsChat
  Restart the game.

HOW TO USE
  It works on the game's own chat windows, so every chat setting, channel and filter keeps working.

  - The buttons on the left of the chat are gone. Click the menu button (three lines) at the right of the tabs for:
    Friends and social, Guild, Chat channels, Emotes, Copy chat, Jump to newest, Font size, New chat tab,
    Move tabs between boxes, Rebuild default tabs, Lock boxes in place, Chat settings.
  - On first login it sets up the tabs Main, Raid, Guild, Whisper and Party (plus the combat Log).
    Main shows everything; the other tabs show only their own chat.
  - Right-click any tab to move it to the other box, rename it, open its chat settings or close it.
    "More options" opens the game's own tab menu.
  - Drag a tab to move its box. Drag the bottom-right corner to resize. Lock both boxes from the menu.
  - Box 2 has a + (new tab in this box) and an x (close the box; its tabs go back to the main box).
  - Click a box (or one of its tabs) to type there - the input line moves under the box you clicked.
  - Left-click a player's name in chat to open their menu (Whisper, Invite, Who...). Prefer the game's
    click-to-whisper? Type /pchat whisperclick.
  - When you're scrolled up, an arrow at the bottom-right jumps back to the newest line. Shift + mouse wheel
    jumps to the top or bottom.

COMMANDS
  /pchat         help
  /pchat tabs    put back any missing default tab and fix its settings
  /pchat reset   rebuild the default tabs (closes your other tabs - it asks first)
  /pchat copy    copy chat
  /pchat lock    lock or unlock the boxes
  /pchat whisperclick   left-click on a name: player menu (default) or start a whisper
